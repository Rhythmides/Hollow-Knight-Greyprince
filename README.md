# Hollow Knight: Greyprince

> An unofficial Hollow Knight fan-made project focused on Zote and his adventures.

## About

**Hollow Knight: Greyprince** is an unofficial fan-made project inspired by Team Cherry's *Hollow Knight*.

The project explores an original adventure centered around Zote, while introducing new gameplay systems, environments, characters, abilities, items, and stories.

This project is **not affiliated with, endorsed by, or sponsored by Team Cherry**.
